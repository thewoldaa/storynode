# Development log

One file per day, written at the end of a session. What moved, what was
decided, what is blocked, what the next session should pick up.

This log is public. It describes the work — decisions, trade-offs, blockers —
and not the machine, the person, or anything private. That constraint is the
point: a log written for a public repository stays useful, because it explains
reasoning rather than narrating activity.

```
YYYY-MM-DD.md
```
